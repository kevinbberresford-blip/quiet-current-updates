# Quiet Current — Android preview downloads

Quiet Current is an offline personal sound-mixing app with six goal-based starting points, adjustable binaural tones, ambient music, piano, softened rain and bowl recordings. It includes a twelve-slider equalizer, saved mixes, stock reset and dark/light appearance.

**[Download Quiet Current 0.2.0 for Android](https://github.com/kevinbberresford-blip/quiet-current-updates/releases/download/android-v0.2.0/QuietCurrent-0.2.0.apk)** · [Release details](https://github.com/kevinbberresford-blip/quiet-current-updates/releases/tag/android-v0.2.0)

The installer is about 109 MiB and requires Android 8.0 or newer. Download the APK on your phone and open it to start installation. If Android asks, allow installation from the browser or Files app you used. Stereo headphones keep the left and right tones separate.

This is a development preview. It has been tested on an Android emulator; physical-phone and headphone listening are the next checks. The app makes no medical or treatment claims.
